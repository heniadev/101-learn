# context/changes

Zmiany w toku — jedna praca, jeden katalog: `context/changes/<change-id>/`.

Katalog zmiany zakłada `/101-new`, a rozpoznaje go plik tożsamości
`change.md` (identyfikator, tytuł, status, daty). Wszystko, co dotyczy tej
jednej zmiany, mieszka tutaj razem: rozpoznanie kodu, przemyślenie ramy,
plan, przeglądy.

Skończoną zmianę przenosi do `context/archive/` polecenie `/101-archive`.
