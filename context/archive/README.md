# context/archive

Zmiany zakończone, przeniesione tutaj z `context/changes/` przez
`/101-archive`.

Ten katalog jest z założenia tylko do odczytu — historii się nie
przepisuje. Skille 101 odmawiają zapisu w tym miejscu; powrót do
zamkniętego tematu oznacza otwarcie nowej zmiany, nie edycję starej.
